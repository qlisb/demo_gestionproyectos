# dashboard_mb

Mapping dashboard built with React, Vite, Leaflet and Esri-Leaflet.

Overview

This repository contains an interactive web dashboard for managing and visualizing projects and spatial data. Key stacks:

- React (v19)
- Vite
- Leaflet + React-Leaflet
- Esri-Leaflet for ArcGIS FeatureService integration

Quick start

1. Install dependencies

   npm install

2. Start development server

   npm run dev

3. Build for production

   npm run build

Configuration

- Feature service base URL is in `src/App.jsx` (FEATURE_SERVICE constant). Update before pushing or set via env if you prefer.
